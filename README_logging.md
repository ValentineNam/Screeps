# Система логирования

## Описание
Система логирования позволяет контролировать, какие сообщения будут выводиться в консоль, с разделением на уровни важности.

## Уровни логирования (в порядке убывания важности):
- `ERROR` - критические ошибки (уровень 0)
- `WARN` - предупреждения (уровень 1) 
- `INFO` - информационные сообщения (уровень 2)
- `DEBUG` - отладочные сообщения (уровень 3)

## Как включать/отключать уровни логов

### 1. Включение/отключение одного уровня:
```javascript
// Включить уровень DEBUG
global.setLogLevel('DEBUG', true);

// Отключить уровень DEBUG
global.setLogLevel('DEBUG', false);

// Включить уровень WARN
global.setLogLevel('WARN', true);
```

### 2. Включение/отключение нескольких уровней сразу:
```javascript
// Включить только ERROR и WARN
global.setLogLevels({ ERROR: true, WARN: true, INFO: false, DEBUG: false });

// Включить ERROR, WARN и INFO, отключить DEBUG
global.setLogLevels({ ERROR: true, WARN: true, INFO: true, DEBUG: false });

// Отключить все уровни
global.setLogLevels({ ERROR: false, WARN: false, INFO: false, DEBUG: false });
```

### 3. Проверка текущих настроек:
```javascript
// Получить текущие настройки уровней логирования
const currentLevels = global.getLogLevels();
console.log(currentLevels); // Покажет { ERROR: true, WARN: true, INFO: false, DEBUG: false }
```

## Как смотреть настройки в памяти
Все настройки хранятся в `Memory.logs`, вы можете посмотреть текущие настройки так:
```javascript
console.log(Memory.logs);
```

## Примеры использования в коде
В коде используются следующие вызовы:
```javascript
log('ERROR', 'Сообщение об ошибке', creep);  // Выведется только если ERROR включен
log('WARN', 'Предупреждение', 'System');     // Выведется только если WARN включен
log('INFO', 'Информационное сообщение');    // Выведется только если INFO включен
log('DEBUG', 'Отладочное сообщение', creep); // Выведется только если DEBUG включен
```

## Настройка по умолчанию
По умолчанию включены:
- `ERROR` - всегда включен
- `WARN` - всегда включен
- `INFO` - отключен
- `DEBUG` - отключен

Это позволяет видеть только важные сообщения и не засорять консоль отладочной информацией.

## Глобальные функции
Следующие функции доступны в глобальной области видимости:
- `global.setLogLevel(level, enabled)` - установить уровень логирования
- `global.setLogLevels(levels)` - установить несколько уровней логирования
- `global.getLogLevels()` - получить текущие уровни логирования
